# Life Dashboard

커리어 · 아마존 셀링 · 육아 · 운동 · 집 관리(테넌트)를 한 화면에서 관리하는 개인 대시보드.
빌드 없이 `index.html` 파일 하나로 동작합니다.

## 사용법
- 브라우저에서 `index.html` 열기 (또는 GitHub Pages로 배포 → Settings › Pages › Branch 선택)
- 데이터는 브라우저 localStorage에 저장 → 다른 기기로 옮길 땐 하단 **백업 내보내기/불러오기**

## 구성
| 탭 | 내용 |
|---|---|
| ☀️ 오늘 | 영역별 요약, **오늘 집중 3가지**(최대 3개 제한), 빠른 추가, 마감 지난 일 |
| 💼 커리어 | 목표 진행률, 할 일, 메모 |
| 📦 아마존 | 런칭 체크리스트, 제품별 마진 계산, 수입/지출 기록 |
| 👶 육아 | 다가오는 일정, 할 일/살 것, 메모 |
| 🏃 운동 | "오늘 했다" 원클릭 체크, 주간 목표, 연속 기록, 최소 버전 |
| 🏠 집 관리 | 테넌트·월 입금 체크, 계약 만료 경고, 3번째 테넌트 준비 체크리스트·후보 관리 |
